# Contributing

Thank you for your interest in contributing to the RAG Tutorials repository! We welcome contributions from the community.

## Ways to Contribute

- **Bug Reports**: Report issues or bugs you encounter
- **Feature Requests**: Suggest new tutorials or improvements
- **Code Contributions**: Fix bugs, add features, or improve existing code
- **Documentation**: Improve tutorials, add examples, or fix typos
- **Tutorials**: Create new RAG implementations or techniques

## Getting Started

1. Fork the repository
2. Create a new branch for your changes
3. Make your changes
4. Test your changes locally
5. Submit a pull request

## Submitting Issues

When reporting bugs or requesting features, please include:

- Clear description of the issue or request
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Environment details (Python version, OS, etc.)

## Pull Request Guidelines

- Use clear, descriptive commit messages
- Include documentation for new features
- Test your changes before submitting
- Keep changes focused and atomic
- Update requirements.txt if adding new dependencies

## Code Standards

- Follow existing code style and structure
- Add comments for complex logic
- Include error handling where appropriate
- Use meaningful variable and function names

## Tutorial Contributions

When adding new tutorials:

- Include a detailed README in the tutorial folder
- Provide working example code
- Add requirements.txt with all dependencies
- Include sample data or clear instructions for data setup
- Test the tutorial from start to finish
